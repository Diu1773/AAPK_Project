## 구현 내용

### 1. Worker에 자체 측광 추가 (`ExtinctionFitWorker`)

**새 메서드: `_run_allstar_photometry()`**
- `step7_dir/idmatch_{fname}.csv` → 프레임별 (x, y, source_id) 로드
- FITS 이미지 로드 (cropped 우선, 없으면 원본)
- `cache_dir/detect_{fname}.json`에서 FWHM 로드
- 구경 파라미터 계산 (aperture_photometry_worker.py와 동일 공식):
  ```
  r_ap = max(ap_scale × fwhm, min_r_ap)
  r_in = max(ann_in_scale × fwhm, r_ap + gap)
  r_out = max(r_in + ann_out_scale × fwhm, r_in + min_width)
  ```
- `_circle_mask` + `_phot_one_target` 로직을 인라인 (step9에서 import하면 순환 의존성 위험)
- 각 별의 instrumental mag 계산: `mag = -2.5 × log10(flux)`
- 출력: `[file, source_id, ID, mag_inst, airmass, date, filter]` DataFrame

**새 메서드: `_run_ensemble_fit()`**
- 각 별 i의 median magnitude 계산: `median_i = median(mag_ij across frames j)`
- `Δm_ij = mag_ij - median_i` (per-star ZP 제거)
- 날짜별/필터별 그룹핑
- `Δm vs X (airmass)` 피팅: `Δm = k × (X - X_median)` with sigma clipping
- sigma clipping으로 변광성, 불량 측정 자동 제거
- 기존 `_robust_linfit()`, `_robust_quadfit()` 재사용

### 2. Worker `run()` 분기

```python
def run(self):
    if self.mode == "ensemble":
        # Step 7 데이터로 자체 측광 → 앙상블 피팅
        phot_df = self._run_allstar_photometry()
        self._run_ensemble_fit(phot_df)
    else:
        # 기존 Gaia absolute 모드 (step 9 데이터 필요)
        self._run_gaia_absolute()  # 현재 run() 코드 리팩토링
```

## 핵심 알고리즘

### 앙상블 Median-Subtraction
```
for each star i:
    median_i = median(mag_ij for all frames j where star i detected)
for each measurement (i, j):
    delta_m_ij = mag_ij - median_i

group by (date, filter):
    fit: delta_m = k1 × X + c  (with sigma clipping)
    optional: delta_m = k1 × X + k2 × X² + c  (quadratic)
```

장점:
- 별 고유 밝기 차이 자동 제거
- 변광성은 sigma clipping으로 제거
- Gaia 불필요, step 7만으로 동작
